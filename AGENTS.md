# Instructions for this public repository

- Keep only thirds.ai product content here. Do not add private source links, personal names, personal email, workstation paths, or credentials.
- Use fictional names in examples. Keep API keys in a secret store. Do not print signed download links in check logs.
- Put each agent skill in `skills/<name>/SKILL.md`. Keep its tool names and product links accurate.
- Run `python3 scripts/check_consistency.py --static` before a public change. Run the live check when a skill, MCP tool, or linked product guide changes.
- Use the separate `thirdsai` GitHub login for this repository. Public commits use the thirds.ai identity.
